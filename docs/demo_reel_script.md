# 110-second demo reel script (record a genuine run)

**0–10s — Problem:** “Students often reuse generic resumes. This prototype compares a resume with a target job description and gives structured, evidence-based feedback.”

**10–35s — Prompt experiment:** Show prompt v1 and explain its 40/30/20/10 rubric. Show v3 and point out evidence-only rules, insufficient-input handling and strict JSON. Do not claim measured superiority unless you have run the same cases on the same model and recorded results.

**35–85s — Working demo:** Open the local Streamlit app. Paste the synthetic sample resume and job description from `test-data/`. Click Analyze match. Show score categories, strengths, gaps, next steps and download JSON. State clearly that the included local demo mode uses deterministic lexical heuristics, not an external LLM.

**85–105s — Testing and limitations:** Show test matrix with 12 cases including edge/invalid cases. Mention limitations: heuristic scoring, no provider integration in this build, human review required.

**105–110s — Next steps:** “Next we plan to connect a selected LLM provider, validate structured outputs and compare prompt versions under controlled tests.”

Record screen with captions or voice-over. Keep final reel between 90 and 150 seconds. Upload to Drive or unlisted YouTube and enable anyone-with-link viewing.
